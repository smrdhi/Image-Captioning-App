# 🖼️ AI Image Captioning using BLIP

An AI-powered image captioning application that automatically generates descriptive captions for uploaded images using the BLIP (Bootstrapping Language-Image Pre-training) model. The application features an interactive web interface built with Gradio and uses the Hugging Face Inference API for real-time caption generation.

## 🚀 Features

- Upload an image through a simple web interface.
- Automatically generates natural language captions.
- Uses the BLIP vision-language model.
- Interactive Gradio interface for easy user interaction.
- Real-time inference using the Hugging Face Inference API.

## 🛠️ Tech Stack

- Python
- Gradio
- Hugging Face Inference API
- BLIP Image Captioning Model
- Pillow
- Requests
- Base64

## ▶️ How to Run

1. Clone the repository.
2. Install the required dependencies.
3. Configure your Hugging Face API key.
4. Open and run `image_captioning_blip.ipynb`.

## ▶️ Usage

1. Configure your Hugging Face API key.
2. Run the notebook.
3. Launch the Gradio interface.
4. Upload an image.
5. The application generates a descriptive caption for the uploaded image.
